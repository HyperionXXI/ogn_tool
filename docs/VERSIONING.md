# Versioning Policy for ogn_tool

ogn_tool uses Semantic Versioning (SemVer):

- Tags follow the format: vMAJOR.MINOR.PATCH (e.g., v1.1.0)
- MAJOR: incompatible changes
- MINOR: new features
- PATCH: bugfixes

## Tagging Policy
- Only version tags (no descriptive tags)
- Release notes describe features and changes
- Annotated tags are used for metadata and release messages

## Example Roadmap
- v1.0.0: initial network engineering engine
- v1.1.0: reporting architecture
- v1.2.0: spatial exploration engine
- v1.3.0: temporal network intelligence
- v2.0.0: major architecture changes

## Historical Note
Previous tags reflected technical milestones and roadmap progression.

## Best Practices
- Tag only stable, tested releases
- Use annotated tags for all releases
- Document major changes in release notes
