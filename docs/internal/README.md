# Internal Documentation

This directory contains working notes, audits, cleanup plans, and
historical analysis documents.

Status:
- non-canonical
- developer-facing
- may lag behind code or architecture decisions

Use this directory for:
- audits
- refactor plans
- import/dead-code analysis
- temporary design notes

Do not use this directory as the primary source of truth for:
- architecture rules
- runtime contracts
- report contracts
- repository classification

Canonical documentation lives in:
- `docs/architecture/`
- selected explanatory documents in `docs/core/`
