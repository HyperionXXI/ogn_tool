# RF Documentation Collections

This directory contains specialized RF domain documentation collections.
Examples include:
- `rf_analysis/`
- `rf_data/`
- `rf_features/`
- `rf_models/`
- `stations/`

Status:
- domain-specific
- useful reference material
- not primary architecture governance

Canonical architecture and contract documents live in:
- `docs/architecture/`
- `docs/core/`

When in doubt:
- use `docs/architecture/` for rules and contracts
- use these directories for domain explanation and specialized reference
